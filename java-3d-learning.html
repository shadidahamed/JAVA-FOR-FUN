🚀 Java ৩ডি লার্নিং

গল্পের মতো করে Java শেখো — AI বন্ধু তোমার সাথে আছে!

🌍 ভাষা কেন দরকার?
পৃথিবীতে মানুষ অনেক ভাষায় কথা বলে। তাই সবাই যাতে একে অপরের সাথে কথা বলতে পারে, সেজন্য English কে সাধারণ ভাষা হিসেবে নেওয়া হয়েছে।

কম্পিউটারও ঠিক তেমনই। সে আমাদের বাংলা বা ইংরেজি বোঝে না। তার নিজস্ব ভাষা আছে — ০ এবং ১ (Zero and One)।
⚡ ০ এবং ১ মানে কী?
১ (One) = Current পাস হচ্ছে → ON
০ (Zero) = Current পাস হচ্ছে না → OFF

AI এর ডান হাতে 1 আর বাম হাতে 0 ভাসছে। এটাই কম্পিউটারের আসল ভাষা।

আমরা যে কোড লিখি সেটা Source Code। উদাহরণ: Hello.java

Compiler হলো এমন সফটওয়্যার যা তোমার লেখা কোডকে কম্পিউটার বুঝতে পারে এমন ভাষায় রূপান্তর করে।
Java-তে javac সরাসরি ০-১-এ না নিয়ে Bytecode নামের মাঝামাঝি ভাষায় পরিণত করে। তারপর JVM সেটাকে ০-১ করে চালায়।
🔄 Compiler vs Interpreter
Compiler → পুরো কোড একবারে অনুবাদ করে তারপর চালায় (C, C++, Java)।
Interpreter → লাইন বাই লাইন বুঝে চালায় (Python, JavaScript)। দোভাষীর মতো।

📝 Class মানে Blueprint (নকশা)
ধরো স্কুলে ক্রিকেট টুর্নামেন্ট হচ্ছে। স্যার একটা খালি ফর্ম বানিয়েছেন। সেই ফর্মটাই হলো Class।

ফর্মে যা যা থাকবে: নাম, রোল, শ্রেণি, শাখা — এগুলোই Class-এর ভেতরের Variable। 
public class Student {
    String name;      // নামের জায়গা
    int roll;         // রোলের জায়গা
    String className; // শ্রেণির জায়গা
    String section;   // শাখার জায়গা
}
🧒 Object মানে ভরাট ফর্ম
রহিম স্যারের কাছ থেকে ফর্ম নিল → নিজের তথ্য লিখে পূরণ করল → এটা হয়ে গেল Object।
করিমও একটা ফর্ম নিল → আরেকটা Object তৈরি হলো।

একটা Class থেকে অনেক Object বানানো যায়। 
Student rahim = new Student();
rahim.name = "রহিম";
rahim.roll = 5;
rahim.className = "নবম";
rahim.section = "ক";

Student karim = new Student();
karim.name = "করিম";
karim.roll = 12;
💻 পুরো উদাহরণ কোড
public class Student {
    String name;
    int roll;
    String className;
    String section;

    void showInfo() {
        System.out.println("নাম: " + name);
        System.out.println("রোল: " + roll);
        System.out.println("শ্রেণি: " + className);
        System.out.println("শাখা: " + section);
    }

    public static void main(String[] args) {
        Student rahim = new Student();
        rahim.name = "রহিম";
        rahim.roll = 5;
        rahim.className = "নবম";
        rahim.section = "ক";

        Student karim = new Student();
        karim.name = "করিম";
        karim.roll = 12;
        karim.className = "নবম";
        karim.section = "খ";

        System.out.println("রহিমের ফর্ম:");
        rahim.showInfo();

        System.out.println("করিমের ফর্ম:");
        karim.showInfo();
    }
}

⚙️ Method (কাজের ব্লক)
Method হলো কাজের ব্লক যেটা বারবার ব্যবহার করা যায়।
main method → প্রোগ্রাম এখান থেকে শুরু হয়।
showInfo() → সাধারণ কাজের জন্য।
📚 Method-এর সব ধরন

১. Return Type অনুযায়ী

ধরনমানেউদাহরণ
voidকিছু ফেরত দেয় নাvoid showInfo() { ... }
Return করাএকটা মান ফেরত দেয়int getRoll() { return roll; }

২. Parameter অনুযায়ী

ধরনমানে
No Parameterকোনো ইনপুট নেয় না
With Parameterইনপুট নেয়
Multiple Parameterএকাধিক ইনপুট নেয়

৩. static অনুযায়ী

static → object না বানিয়েই কল করা যায় (main method)।
Non-static → object বানিয়ে কল করতে হয়।

৪. বিশেষ Method

• main → প্রোগ্রাম শুরু
• Constructor → object তৈরির সময় অটো চলে
• Getter / Setter → private variable পড়া/লিখা
