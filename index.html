হাই! আমি JavaBot। আজ আমরা একসাথে Java শিখব — কম্পিউটারের সাথে কথা বলার একটা ভাষা।

পৃথিবীতে মানুষ অনেক ভাষায় কথা বলে। কিন্তু সবাই যেন বুঝতে পারে, তাই আমরা English ব্যবহার করি। ঠিক তেমনই কম্পিউটারের নিজস্ব ভাষা আছে — সেটা হলো ০ আর ১।

এই ওয়েবসাইটে আমি ধাপে ধাপে সবকিছু বুঝিয়ে বলব। তুমি শুধু Next চাপতে থাকো।

কম্পিউটারের ভাষা: ০ এবং ১

Binary World

মানুষের মতো কম্পিউটারও আমাদের কথা সরাসরি বোঝে না। তার ভাষা শুধু Zero (০) আর One (১)।

০ মানে Off / Current নেই। ১ মানে On / Current আছে।

0️⃣
Off / Current নেই
⟷
1️⃣
On / Current আছে

আমরা যে কোড লিখি, সেটা একটা Programming Language। Java-তে লেখা কোডকে বলা হয় Source Code।

Source Code থেকে Bytecode

javac Compiler

ধরো আমাদের একটা ফাইল আছে: Hello.java। এটা হলো Source Code।

এই ফাইলকে javac নামের টুল দিয়ে চালালে Compiler কাজ করে।

📄
Hello.java
Source Code
→
⚙️
javac
Compiler
→
📦
Hello.class
Bytecode

Compiler হলো এমন সফটওয়্যার যা প্রোগ্রামারের লেখা কোডকে কম্পিউটার বোঝার ভাষায় রূপান্তর করে।

Java সরাসরি ০-১ এ নেয় না। আগে Bytecode নামক মাঝামাঝি ভাষায় পরিণত করে। তারপর JVM (Java Virtual Machine) সেই Bytecode-কে ০ ও ১ এ রূপান্তর করে।

প্রথম Java প্রোগ্রাম

Hello.java

public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }

public → সবার জন্য খোলা। class Hello → ক্লাসের নাম ফাইলের নামের সাথে মিলতে হবে (Hello.java)।

main মেথড থেকেই প্রোগ্রাম শুরু হয়। Java ঠিক এই নামই চায়।

Class = নকশা / Blueprint

খালি ফর্মের গল্প

স্কুলের ক্রীড়া প্রতিযোগিতায় অংশ নিতে একটা আবেদন ফর্ম দিতে হয়। সেই খালি ফর্মটাই হলো Class — শুধু নকশা।

নাম, রোল, শ্রেণি, শাখা — জায়গাগুলো নির্ধারণ করা আছে, কিন্তু এখনো খালি।

public class Student { String name; // নামের জায়গা int roll; // রোলের জায়গা String className; // শ্রেণির জায়গা String section; // শাখার জায়গা }

Object = ভরাট ফর্ম

রহিম ও করিমের গল্প

রহিম স্যারের কাছ থেকে ফর্ম নিলো এবং নিজের তথ্য লিখে ভরালো। এখন সেটা একটা Object।

একই Class থেকে অনেক Object তৈরি করা যায়।

Student rahim = new Student(); rahim.name = "রহিম"; rahim.roll = 5; rahim.className = "নবম"; rahim.section = "ক"; Student karim = new Student(); karim.name = "করিম"; karim.roll = 12;

Data Types

কোনটা কী রাখে

int → পূর্ণ সংখ্যা (10, -5, 0)
float / double → দশমিক
String → লেখা / কথা
char → একটি অক্ষর
boolean → true অথবা false
long → বড় পূর্ণ সংখ্যা
byte → খুব ছোট সংখ্যা

int roll = 5; double pi = 3.14159; String name = "রহিম"; boolean isPassed = true;

Method = কাজের ব্লক

বারবার ব্যবহার করা যায়

Method হলো কাজের একটা ব্লক। void মানে কিছু ফেরত দেয় না। Return টাইপ থাকলে মান ফেরত দেয়।

void showInfo() { System.out.println("নাম: " + name); } int getRoll() { return roll; }

সম্পূর্ণ উদাহরণ

Student.java

public class Student { String name; int roll; String className; String section; void showInfo() { System.out.println("নাম: " + name); System.out.println("রোল: " + roll); System.out.println("শ্রেণি: " + className); System.out.println("শাখা: " + section); } public static void main(String[] args) { Student rahim = new Student(); rahim.name = "রহিম"; rahim.roll = 5; rahim.className = "নবম"; rahim.section = "ক"; rahim.showInfo(); } }

Method-এর সব ধরন

এক নজরে

Return Type: void / মান ফেরত দেয়
Parameter: আছে / নেই
static: object ছাড়াই কল করা যায়
Access: public / private / protected
বিশেষ: main, Constructor, Getter, Setter
