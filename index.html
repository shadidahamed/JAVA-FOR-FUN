ভাষা কেন দরকার?

পৃথিবীতে অনেক মানুষ অনেক ভাষায় কথা বলে। সবাইকে একসাথে কথা বলতে গেলে একটা সাধারণ ভাষা দরকার হয়। সেই ভাষা হলো ইংরেজি।

কম্পিউটারও ঠিক তেমন। কম্পিউটার শুধু ০ আর ১ বোঝে। আমরা যে ভাষায় কথা বলি, সেটা সে বোঝে না।

তাই কম্পিউটারের সাথে কথা বলার জন্য আমাদের দরকার প্রোগ্রামিং ল্যাঙ্গুয়েজ।

০ = অফ (বিদ্যুৎ নেই)
১ = অন (বিদ্যুৎ আছে)

Java কী?

Java হলো একটা প্রোগ্রামিং ল্যাঙ্গুয়েজ। যেমন আমরা মানুষের সাথে কথা বলতে ইংরেজি ব্যবহার করি, ঠিক তেমন কম্পিউটারের সাথে কথা বলতে Java ব্যবহার করি।

Java দিয়ে আমরা অ্যাপ, গেম, ব্যাংকিং সফটওয়্যার, ওয়েবসাইটের ব্যাকএন্ড তৈরি করতে পারি।

মনে রাখো: Java ≠ JavaScript
দুটো সম্পূর্ণ আলাদা ভাষা।

Source Code → Bytecode → JVM

আমরা যে কোড লিখি সেটা Source Code। কম্পিউটার সরাসরি এটা বোঝে না। তাই একটা বিশেষ প্রোগ্রাম লাগে যাকে বলে Compiler।
hello.java
Source Code
↓ javac (Compiler)
hello.class
Bytecode
↓ JVM
০ এবং ১
Machine Code

Bytecode হলো মাঝামাঝি ভাষা। JVM (Java Virtual Machine) এই bytecode কে ০/১ এ রূপান্তর করে।

Class = ছাঁচ (Blueprint)

ক্লাস মানে হলো একটা খালি ফর্ম বা নকশা। যেমন স্কুলে টুর্নামেন্টের আবেদন ফর্ম।

ফর্মটিতে জায়গা রাখা থাকে: নাম, রোল, শ্রেণি, শাখা। কিন্তু এখনো কেউ পূরণ করেনি। এটাই Class।

public class Student { String name; // নামের জায়গা int roll; // রোলের জায়গা String className; String section; }

Object = ভরাট ফর্ম

যখন রহিম ফর্মটি পূরণ করে, তখন সেটা হয়ে যায় একটা Object।
Student rahim = new Student(); rahim.name = "রহিম"; rahim.roll = 5; rahim.className = "নবম"; rahim.section = "ক";

একই ক্লাস থেকে অনেকগুলো অবজেক্ট বানানো যায় (রহিম, করিম...)।

প্রথম প্রোগ্রাম

📄 Hello.java
public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }

Method কী?

Method হলো কাজের ব্লক। একবার লিখে বারবার ব্যবহার করা যায়।
void method → কিছু ফেরত দেয় না
return method → মান ফেরত দেয়
static method → object ছাড়াই চলে
main method → প্রোগ্রাম এখান থেকে শুরু
void showInfo() { System.out.println(name); }
