স্বাগতম Java শেখার জগতে! 🎉

আজ আমরা মজার করে Java শিখব — যে ভাষায় কম্পিউটারের সাথে কথা বলা যায়।

পৃথিবীতে মানুষ ইংরেজি দিয়ে একে অপরের সাথে যোগাযোগ করে। ঠিক তেমনই কম্পিউটারের নিজস্ব ভাষা হলো ০ আর ১।

Java হলো সেই সেতু যেটা আমাদের কথা কম্পিউটার বোঝে।

Java কী?

Java হলো একটি Programming Language।

আমরা যে ভাষায় কথা বলি, কম্পিউটার তা বুঝতে পারে না। কম্পিউটার শুধু ০ আর ১ বোঝে (On / Off)।

বর্তমানে current থাকলে → 1 (On)
current না থাকলে → 0 (Off)

Java vs HTML

HTML যেমন পেজ বানাতে ব্যবহার হয়,
Java তেমন Program / App বানাতে ব্যবহার হয়।

Java vs JavaScript

নাম কাছাকাছি, কিন্তু সম্পূর্ণ আলাদা!

Java → Android App, Banking, Enterprise Software, Minecraft Java Edition

JavaScript → Interactive Website, Web App, Node.js, Browser Games

Source Code → Bytecode → JVM

Hello.java → এটি একটা Source Code।

এটাকে javac নামের টুল দিয়ে চালানো হয়। javac হলো Java-এর Compiler।

Compiler কী?

Compiler হলো এমন সফটওয়্যার যা প্রোগ্রামারের লেখা কোডকে কম্পিউটার বোঝার উপযোগী Machine Code-এ রূপান্তর করে।

Java-এর বিশেষত্ব

Java সরাসরি ০ ও ১-এ নেয় না।
সে Bytecode নামক একটা মাঝামাঝি ভাষায় পরিণত করে।

Bytecode দেখতে এমন: CAFEBABE ...

তারপর JVM (Java Virtual Machine) সেই Bytecode নিয়ে আসল ০,১-এ রূপান্তর করে প্রোগ্রাম চালায়।

অর্থাৎ Java কোনো Compiler নয় — এটি এক প্রকার Language।

File তৈরির নিয়ম

Java Coding করতে হলে সর্বপ্রথম একটা file create করতে হয়।

File-এর নামের পরে .java লেখা থাকতেই হবে।

যেমন pdf-এর ক্ষেত্রে .pdf, jpg-এর ক্ষেত্রে .jpg — ঠিক তেমনই .java।

ভেতরের যে Class-এর নাম দিবে, File-এর নামও একই হতে হবে।

অতএব Class-এর নাম যদি Hello হয়, তবে File-এর নামও Hello.java হতে হবে।

(HTML-এর index.html-এর মতো fixed নাম নয়, Class-এর নাম অনুসারে হয়)

একটা Simple Program

public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }
Hello World

public class Hello — তিনটি জিনিস

public → সবার জন্য খোলা। এই Class-কে অন্য জায়গা থেকেও ব্যবহার করা যাবে। Java-তে access level আছে।

  • public → সবাই দেখতে বা ব্যবহার করতে পারে
  • private → শুধু নিজের মধ্যে ব্যবহার করা যায় (Class-এর বাইরে নয়)
  • protected → সীমিত
  • কিছু না লিখলে → package-private (একই package-এর ভিতরে)

Package কী?

Java-তে Package মানে একটা Folder বা Group যেখানে অনেকগুলো Related Class একই সাথে রাখা হয়।

package school; public class Student { ... } package school; public class Teacher { ... }

এখানে দুটো Class একই Package school-এর ভিতরে।

Class = নকশা / Blueprint / Template

Java-তে সবকিছুই Class-এর ভিতরে লিখতে হয়।

সহজে বুঝতে: Class বা Template হলো কম্পিউটারে আমি কেমন একটা ফর্ম দেখতে পাচ্ছি।

ধরি, স্কুলের ক্রীড়া প্রতিযোগিতা হবে। স্যাররা একটা আবেদন ফর্ম নির্ধারণ করলেন। সেখানে শুধু খালি জায়গা আছে — নাম, রোল, শ্রেণি, শাখা।

এই খালি ফর্মটাই হলো Class — যেখানে শুধু নির্ধারণ করে রাখা হয়েছে কী কী তথ্য থাকবে।

public class Student { String name; // নামের জায়গা int roll; // রোলের জায়গা String className;// শ্রেণির জায়গা String section; // শাখার জায়গা }

এটি কেবল তথ্যের ছাঁচ বানায় না, বরং কাজের নিয়মও দেয়।

Object = ভরাট ফর্ম

যখন কোনো ছাত্র এই ফর্মটি পূরণ করে নিজের তথ্য লিখে ফেলে — তখন সেটা হয়ে যায় একটা Object।

ধরি রহিম ও করিম স্যারের কাছ থেকে ফর্ম নিলো এবং তথ্য দিয়ে পূরণ করলো। তখন সেটি Object-এ পরিণত হলো।

একটি Class-এ অনেকগুলো Object থাকতে পারে।

Student rahim = new Student(); rahim.name = "রহিম"; rahim.roll = 5; rahim.className = "নবম"; rahim.section = "ক"; Student karim = new Student(); karim.name = "করিম"; karim.roll = 12; karim.className = "নবম"; karim.section = "খ";

পুরো Student Program

public class Student { String name; int roll; void showInfo() { System.out.println("নাম: " + name); System.out.println("রোল: " + roll); } public static void main(String[] args) { // রহিম এসে নতুন ফর্ম নিল Student rahim = new Student(); rahim.name = "রহিম"; rahim.roll = 5; // করিম নিজেও একটা ফর্ম নিল Student karim = new Student(); karim.name = "করিম"; karim.roll = 12; System.out.println("রহিমের ফর্ম:"); rahim.showInfo(); System.out.println("করিমের ফর্ম:"); karim.showInfo(); } }
রহিমের ফর্ম: নাম: রহিম রোল: 5 করিমের ফর্ম: নাম: করিম রোল: 12

new Student() মানে → নকশা থেকে একদম নতুন খালি ফর্ম তৈরি করা।

rahim.name = "রহিম" মানে → সেই ফর্মের নামের ঘরে লেখা।

Method-এর সব ধরন

১. Return Type অনুযায়ী

void Method → কিছু ফেরত দেয় না → void showInfo() { ... }

Return করা Method → একটা মান ফেরত দেয় → int getRoll() { return roll; }

২. Parameter অনুযায়ী

No Parameter / With Parameter / Multiple Parameter

৩. static অনুযায়ী

static → object না বানিয়েই কল করা যায় (main method)
Non-static → object বানিয়ে কল করতে হয়

৪. Access Modifier

public / private / protected / default

৫. বিশেষ Method

main, Constructor, Getter, Setter, Predefined, User-defined

public class Student { private String name; private int roll; // Constructor Student(String n, int r) { name = n; roll = r; } // Getter public String getName() { return name; } // Setter public void setRoll(int r) { roll = r; } // void + non-static public void showInfo() { System.out.println("নাম: " + name); System.out.println("রোল: " + roll); } public static void welcome() { System.out.println("স্বাগতম"); } public static void main(String[] args) { welcome(); Student rahim = new Student("রহিম", 5); rahim.showInfo(); } }

এক নজরে সারাংশ

  • public static void main → প্রোগ্রামের শুরু
  • System.out.println → স্ক্রিনে দেখানো
  • void showInfo → সাধারণ কাজের নিয়ম
  • int / String / double → Data Type
  • Comment (//) → নিজে বোঝার জন্য
  • Method → কাজের ব্লক, বারবার ব্যবহার করা যায়
  • Class = নকশা, Object = ভরাট ফর্ম
