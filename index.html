1. Java কি?
🔊

আমরা পৃথিবীতে অনেক জন অনেক ভাষায় কথা বলি। তো পৃথিবীতে সব মানুষের যেরকম বিভিন্ন ভাষায় কথা বলে দেখে একটা problem হচ্ছিল। সবার communication এর জন্যে পরে পৃথিবীতে একটা নির্ধারিত language কে নিয়ে আসতে হয়েছিল। যেটার মাধ্যমে পৃথিবী সব মানুষ সবাই সবার সাথে connect হতে পারবে, কথা বলতে পারবে।

তখন মানুষের মাথায় একটা ভাষা কে বেশি appropriate মনে হচ্ছে, because ওই ভাষাটা বেশি পরিমাণে used হয়, যেটা ছিল English। And এই English ভাষাতে পৃথিবীর সবাই একজন আরেকজনের সাথে interact করে, communicate করে।

এখন আমরা computer-এর সাথে, আমি যেভাবে বলছি এইভাবে বলতে পারি না। computer ও ঠিক সেরকম বুঝতে পারে না। like আমরা এক দেশে আরেক দেশে গেলে যেরকম ওই দেশের ভাষা বুঝতে পারে না দেখে আমাদের ইংলিশ ভাষা লাগে। ঠিক তেমনই computer এর একটা নিজস্ব ভাষা আছে। সেই ভাষা ছাড়া অন্য কোন ভাষা আমরা যেগুলো বলি সেগুলো ও কখনোই বুঝতে পারে না।

তো computer এর ভাষা হচ্ছে শূন্য আর এক। অর্থাৎ zero and one।

2. Zero & One
🔊
0
1

এখানে zero and one যেটা আছে, এটা মূলত বুঝাচ্ছে ON বা OFF।

যদি current pass হচ্ছে, এটা বুঝায় ON। অর্থাৎ, one। আর যদি current pass হচ্ছে না, বা electricity নেই বোঝায়, তাহলে হবে zero বা OFF।

💡 1 (ON) → Current pass হচ্ছে, এটা electricity ON বোঝায়।

⚡ 0 (OFF) → Current pass হচ্ছে না, বা electricity নেই বোঝায়, তাহলে 0 বা OFF।

3. Source Code & Hello.java
🔊

আমরা যা হতে যে code লিখি সেটা একটা programming language। তো এখন Java তে যে code টা লেখা হয় তথা একটা Java file ধরে নেওয়া যায়।

এখানে hello.java একটি file। যেটা java code লেখা রয়েছে। এটি একটা source code।

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
Hello World

File-এর নামের পরে অবশ্যই .java লিখতে হবে। ভিতরের class-এর নাম আর file-এর নাম একই হতে হবে। class-এর নাম যদি Hello হয়, তবে file-এর নামও Hello.java হতে হবে।

4. Compiler কী?
🔊

A compiler is a special computer program that translates code written by a program into a language that a computer can understand and execute.

সহজ বাংলায়, compiler হলো এমন একটা software যা program-এর লেখা code-কে computer-এর বোঝার উপযোগী machine code-এ রূপান্তর করে।

Compiler কীভাবে কাজ করে?

  • Program-এর code (C/C++/Java) চেক করে
  • Code-কে translate করে
  • Machine code-এ convert করে
  • Execute (বা executable) করে
  • Output দেয়

Java source code-কে সরাসরি 0 এবং 1-এ না নিয়ে bytecode নামক একটা মাঝামাঝি ভাষায় পরিণত করে।

javac tool দিয়ে compile করলে Hello.class file তৈরি হয়। .class extension বলে দিচ্ছে যে এটি একটি compiled class।

এরপর JVM (Java Virtual Machine) সেই bytecode নিয়ে আসলে 0,1-এ রূপান্তর করে এবং program চালায়।

অর্থাৎ Java কোনো compiler নয়, বরং এটি এক প্রকার language। HTML যেমন page বানাতে use হয়, তেমনি Java program / app বানাতে use হয়।

6. Class & Object (গল্পসহ)
🔊

Class মানে নকশা / blueprint / template। Java-তে সবকিছুই class-এর ভিতরে লিখতে হয়।

সহজে বুঝতে: ধরো স্কুলের ক্রীড়া প্রতিযোগিতা হবে। শিক্ষকেরা একটা খালি আবেদন ফর্ম বানালেন। সেই খালি ফর্মটাই হলো Class।

public class Student {
    String name;      // নামের জায়গা
    int roll;         // রোলের জায়গা
    String className; // শ্রেণীর জায়গা
    String section;   // শাখার জায়গা

    void showInfo() {
        System.out.println("নাম: " + name);
        System.out.println("রোল: " + roll);
    }
}

যখন কোনো ছাত্র এই ফর্মটি পূরণ করে নিজের তথ্য লিখে ফেলে, তখন সেটা হয়ে যায় একটা Object।

রহিম ও করিম স্যারের কাছ থেকে ফর্ম নিয়ে পূরণ করলো → দুটো Object তৈরি হলো।

public class Student {
    String name;
    int roll;

    void showInfo() {
        System.out.println("নাম: " + name);
        System.out.println("রোল: " + roll);
    }

    public static void main(String[] args) {
        Student rahim = new Student();
        rahim.name = "রহিম";
        rahim.roll = 5;

        Student karim = new Student();
        karim.name = "করিম";
        karim.roll = 12;

        System.out.println("রহিমের ফর্ম:");
        rahim.showInfo();
        System.out.println("করিমের ফর্ম:");
        karim.showInfo();
    }
}
রহিমের ফর্ম:
নাম: রহিম
রোল: 5
করিমের ফর্ম:
নাম: করিম
রোল: 12
7. Package & Access Modifier
🔊

Package = folder বা group যেখানে অনেকগুলো related class একসাথে রাখা হয়।

package school;

public class Student { ... }
public class Teacher { ... }

Access Level:

  • public → সবার জন্য খোলা, অন্য জায়গা থেকেও ব্যবহার করা যায়
  • private → শুধু নিজের class-এর ভিতরে
  • protected → সীমিত (একই package + subclass)
  • কিছু না লিখলে → package-private (একই package-এর ভিতরে)
