Java কী?

পৃথিবীতে অনেক জন অনেক ভাষায় কথা বলি। সবার communication-এর জন্য একটা নির্ধারিত language দরকার হয়েছিল। সেটা ছিল English।

ঠিক তেমনই computer-এর সাথে আমরা যেভাবে কথা বলি, সেভাবে বলতে পারি না। Computer-এর নিজস্ব ভাষা আছে — শূন্য আর এক (zero and one)।

Zero মানে সাধারণত Off, One মানে On।

Computer শুধু ০ আর ১ বোঝে। তাই আমরা Programming Language ব্যবহার করি যাতে computer-কে নির্দেশ দিতে পারি।

Source Code ও hello.java

আমরা যে code লিখি সেটা একটা programming language-এ লেখা হয়। Java-তে লেখা code একটা Java file-এ থাকে।
📄 Hello.java

এটি একটি Source Code।

public class Hello {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

ফাইলের নাম আর public class-এর নাম একই হতে হয়।

Compiler কী?

javac নামের একটা tool দিয়ে Java code চালানো হয়। এই tool-টা মূলত Java-এর একটি Compiler।
Compiler হলো এমন একটা software যা programmer-এর লেখা code-কে computer-এর বোঝার উপযোগী representation-এ রূপান্তর করে।

Java-তে javac source code-কে সরাসরি ০/১-এ না নিয়ে Bytecode-এ পরিণত করে।

Bytecode ও JVM

Bytecode হলো intermediate code। JVM (Java Virtual Machine) এই bytecode execute করে।

Class = ছাঁচ (Blueprint)

Class মানে হলো নকশা বা template। যেমন স্কুলে টুর্নামেন্টের খালি আবেদন ফর্ম।
public class Student {
  String name;    // নামের জায়গা
  int roll;       // রোলের জায়গা
  String className; // শ্রেণির জায়গা
  String section;  // শাখার জায়গা
}

Object = ভরাট ফর্ম

যখন রহিম বা করিম ফর্ম পূরণ করে, তখন সেটা হয়ে যায় Object।
Student rahim = new Student();
rahim.name = "রহিম";
rahim.roll = 5;
rahim.className = "নবম";
rahim.section = "ক";

একই Class থেকে অনেকগুলো Object বানানো যায়।

পুরো Student Program

📄 Student.java
public class Student {
  String name;
  int roll;
  String className;
  String section;

  public void showInfo() {
    System.out.println("নাম: " + name);
    System.out.println("রোল: " + roll);
    System.out.println("শ্রেণি: " + className);
    System.out.println("শাখা: " + section);
  }

  public static void main(String[] args) {
    Student rahim = new Student();
    rahim.name = "রহিম";
    rahim.roll = 5;
    rahim.className = "নবম";
    rahim.section = "ক";

    Student karim = new Student();
    karim.name = "করিম";
    karim.roll = 12;
    karim.className = "নবম";
    karim.section = "খ";

    System.out.println("রহিমের ফর্ম");
    rahim.showInfo();
    System.out.println("করিমের ফর্ম");
    karim.showInfo();
  }
}

Data Types

ডেটার টাইপ কোনটা কী রাখে?
int → পূর্ণসংখ্যা (5, -3, 100)
float → দশমিক (99.50f) — শেষে f লাগে
double → বড় দশমিক (3.14159)
String → টেক্সট ("রহিম")
char → একটা অক্ষর ('A')
boolean → true / false
long → বড় পূর্ণসংখ্যা (শেষে L)
byte → খুব ছোট সংখ্যা (-128 থেকে 127)

Method কী?

Java-তে function-কে Method বলা হয়। Method হলো কাজের block যা বারবার ব্যবহার করা যায়।
public void showInfo() {
  System.out.println("নাম: " + name);
}

rahim.showInfo(); → Method call করা হলো

void → কিছু ফেরত দেয় না
int / String → মান ফেরত দেয়
static → object ছাড়াই চলতে পারে
main → প্রোগ্রাম এখান থেকে শুরু
